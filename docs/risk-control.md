# 风控管理

new-api 的管理入口是 `/console/risk_control`。普通管理员可调查和处置权限范围内的账号、IP，并处理事件；风控设置与豁免名单仅允许 root 修改。

## 管理流程

- **风控概览**：查看检测开关、守卫演练或执行模式、有效规则、日志覆盖、当前禁用账号与生效 IP 封禁、待处理告警。最近扫描信息来自主库保存的实际扫描记录，不依据开关推断任务是否运行。
- **排行榜与多账号关联**：搜索、排序和主列表分页由服务端完成。筛选和页码保存在 URL；共享出口只能作为关联证据，不能单独证明账号属于同一人。
- **对象详情**：展示主库当前状态、覆盖或重叠封禁、调用证据与事件。网段详情只展示处置与事件记录，调用证据需查看具体 IP。状态读取失败时保留调查证据，并阻止依赖未知状态的处置。
- **批量处置**：先明确勾选目标，再核对逐项影响，填写原因并确认。每次最多 100 项，执行时重新检查主库角色。只处理勾选目标，不因同 IP 自动选中或处置其他账号；返回每项成功、失败或跳过的结果。
- **事件处理**：可标记待处理、已确认、误报，分配给已启用的管理员并保存备注。更新有版本检查，防止覆盖其他管理员刚保存的内容；每次处理同时保存历史记录。

手动禁用账号为永久禁用，临时禁用账号可转为永久；状态、原因和到期时间在同一事务更新。root 账号不可禁用，管理员当前来源 IP 不可手动封禁。IP 封禁必须明确临时或永久，解除操作仅删除所选封禁记录，其他覆盖封禁或静态黑名单仍可能生效。

全局豁免跳过请求风险拦截与自动处置，并从扫描统计中排除；账号豁免仅防止自动禁用账号。手动管理操作仍按权限执行，添加豁免不会删除已有封禁记录。

## 配置与规则追溯

设置按实时防护、扫描规则、黑名单、豁免账号、处置阶梯与 IP 归属地分组，整页一次校验、一次事务保存，成功后显示返回的生效值。密钥不回显，留空表示保留。

扫描规则保存稳定 `id` 和可读 `name`；旧规则自动补充标识，首次保存后持久化。编辑或重排已保存的规则不会改变标识。事件保存命中时的版本、指标、窗口、阈值、观测值、配置动作，以及实际处置期限和违规次数。历史事件没有快照时显示缺失提示，不使用当前配置替代历史证据。

扫描命中预览与实际扫描共用统计和严格 `>` 阈值判定，使用当前表单规则与已保存的全局豁免名单，只读日志。与扫描一致，最多评估指标排名前 500 个目标。实时守卫使用既有演练模式收集告警，阈值为 `>=`，可直接查看对应演练和处置事件。

## 数据与运行状态

日志统计读取日志库；账号、IP 封禁、事件、事件处理历史和扫描执行记录读取主库。查询不跨库连接。新字段与表由常规迁移和快速迁移共同覆盖，规则快照使用 TEXT 存储，适用于 SQLite、MySQL 和 PostgreSQL。

最近主节点扫描记录可由其他节点读取。本节点后台启动、封禁缓存同步及事件写入异常信息只代表当前请求节点。实时守卫窗口按节点独立统计；其他节点的封禁缓存通常在一分钟内同步。

概览事件统计以近 24 小时已落库记录为准，聚合事件的记录数与命中次数不同。告警聚合可能延迟；开关开启不能补回历史 IP、UA 或消费日志。拦截、告警及其处理历史按配置保留期共同清理，封禁与解封事件及处理历史保留。扫描记录按同一保留天数清理。

## 管理 API

以下 `/api/risk` 接口要求管理员身份；批量接口中的豁免动作额外要求 root。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /overview` | 概览、真实扫描结果与本节点状态；独立分区失败时返回可用数据和 `errors` |
| `GET /rankings?paginated=true` | 服务端分页、`keyword` 搜索和排序，返回 `items`、`total`、`meta`；保留原 top N 查询兼容性 |
| `GET /multi_account?paginated=true` | 多账号关联的服务端分页与 IP 搜索 |
| `GET /state`、`GET /detail` | 当前状态与对象证据 |
| `GET /rules`、`POST /rules/preview` | 规则元数据与只读命中预览 |
| `GET /events` | 事件分页，支持类型、账号、IP、UA、起止时间、规则、处理状态、负责人筛选 |
| `GET /events/:id/reviews` | 当前事件与最近 100 条处理记录 |
| `PUT /events/:id/review` | 提交 `status`、`note`、`assignee_id`、`version`，检查并发版本 |
| `POST /batch` | `preview: true` 仅核对影响，实际提交逐项复核；账号使用 `user`，封 IP 使用 `ip`，解除指定记录使用 `ip_ban` 与记录 ID |
| `GET/POST /ip_bans`、`DELETE /ip_bans/:id` | 单项 IP 封禁管理 |

`PUT /api/option/risk` 要求 root，只接受风控与 IP 归属地命名空间。字段校验失败返回 `data.field_errors`，全部保存成功返回脱敏后的 `data.options`。
