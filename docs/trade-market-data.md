# 模拟盘钱包、通知与市场资讯

## 资金规则

账户从零开始，先从平台额度或独立游戏币钱包转入后才能交易。1 游戏币 = 1 USDT = 1 美元额度；游戏币按额度单位记账，转入模拟盘要求整币，转回游戏币和平台额度均可按小数转账。

本金和已实现盈利均可自动转出；持仓和挂单占用的资金、全仓浮动盈利不能转出。平台额度与游戏币共用同一份本金，默认每人每天可转出 100 美元盈利，本金转回不占此限额。

只有从游戏币转入、按亏损抵扣顺序结算后还剩的本金(账户的 `coin_principal`)能转回游戏币，盈利只能转出到平台额度。用户可选择先扣游戏币(`coin_first`，默认)或先扣平台额度(`quota_first`)。每次划转前按总资产把亏损记到对应本金；已经结算掉的游戏币本金不会因之后转入额度或改变顺序而恢复。本金转出成额度后剩下的本金不够时，`coin_principal` 也随之减少。游戏币转入与游戏中心的兑换额度共用每人每天 15 个游戏币的上限，转入的币不能绕过上限再转出成额度。

涉及游戏币来源的本金结算必须取得可靠估值：现货按新鲜买一、借币负债按新鲜卖一、合约按新鲜标记价格计价；已确认结果的预测按确定派彩计价，未决预测只使用当前轮次的新鲜报价。缺失或过期行情时暂停相关划转，资产页面仍可按成本或缓存价格展示。仅有现金的账户不依赖行情连接；从节点需要现货估值时会在请求内确认盘口。账户的持久资产版本随资金、持仓、借款和预测结果变化递增；估值后版本变化则重新估值，连续变化时提示稍后重试。

合约与现货借款的穿仓亏空按所选顺序从游戏币与平台额度钱包补齐。先扣平台额度时先用其正余额，不足的再扣游戏币，最后不足部分记成平台额度欠费；游戏币不能为负数。转回平台额度会先抵消负余额。这是站内记账规则，不代表向银行账户自动收款。

游戏币钱包就是游戏中心的钱包(`game_coin_accounts` 和 `game_coin_logs`)。双向划转的两边余额、流水、盈利计数与兑换额度在同一个数据库事务内完成。升级前已有的模拟盘账户 `coin_principal` 为 0，原有资金只能转出到平台额度。

已确认默认值：现货手续费 0.1%，单笔上限 1,000 美元，单交易对持仓上限 5,000 美元；合约最高 20 倍，吃单费 0.04%，挂单费 0.02%，单合约持仓上限 5,000 美元。现货和合约总开关默认关闭。升级不会覆盖数据库中已经保存的配置，管理员可在模拟盘管理页核对实际值。

## 通知

止盈、止损、强平、挂单成交和穿仓扣额度均保留站内通知。站外通知沿用用户个人设置中的邮件、Webhook、Bark 或 Gotify 渠道。

新增的四类交易事件在成交事务内写入待发送状态，主节点只处理已提交的新事件；升级前历史事件不会补发，超过 15 分钟的积压不再发送。每条事件最多尝试发送一次，失败记录日志和状态，站内通知仍保留。进程在领取事件后、实际发出前崩溃时可能漏掉站外提醒，不能将该提醒视为成交凭证。

## 市场资讯

入口为模拟盘的“市场资讯”页，后台“市场资讯”开关控制开放。只请求用户选中的栏目，所有源均显示覆盖范围、更新时间和不可用/过期状态。外部数据只用于展示，不参与撮合或资金结算。

| 栏目 | 来源与范围 | 更新方式 |
| --- | --- | --- |
| 财经日历 | TradingView 网站日历接口，过去 3 天及未来 7 天的重要事件 | 缓存 4 小时；此网站接口可能调整 |
| 强平快照 | Binance USDⓈ-M；每个交易对每秒最多一条，非完整逐笔或跨交易所统计 | WebSocket；每节点保留最近 24 小时最多 200 条，重启清空；需开放合约 |
| 大户持仓样本 | Hyperliquid 公开榜单中净值至少 100 万美元的前 20 个地址，统计 BTC/ETH/SOL/XRP/DOGE 中价值至少 10 万美元的仓位 | 地址池每日更新，持仓缓存 10 分钟；页面显示成功样本数，部分失败会提示 |
| 新闻快讯 | BlockBeats 中文重要快讯，保留来源原文 | 最新 20 条，缓存 10 分钟，需 API key |
| 公司资料 | 原项目中的公司/基金名称、行业和官网 | 静态身份资料；原始资料日期未知，不提供实时市值、估值或管理层信息 |

新闻需要在后端运行环境设置 `BLOCKBEATS_API_KEY`。不要把 key 放到前端或代码仓库；未配置时新闻栏目明确显示未配置。外部 HTTP 和 WebSocket 请求沿用模拟盘的代理设置。缓存失败会保留旧数据并标记过期，不把失败显示为“没有事件”。

Binance [官方强平快照说明](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/ws-streams/market#all-market-liquidation-order-streams)明确限制了快照频率；Hyperliquid 持仓使用[公开 Info API](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/perpetuals)。地址榜属于未文档化来源，不保证长期稳定。
