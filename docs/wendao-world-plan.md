# 问道转向：个人修仙大世界

编制日期：2026-11-03。代码基线：`5c8e5167602aad9c0fa3a9c2bd1aa4989a0a807a`（v2.16.27）。

问道还在开发阶段、没有正式上线。从这一版起，玩法逐步从"三个板块各玩各的"转向**以个人为主体**：玩家是沧澜界里的一名修士，
自己决定当散修、拜入宗门，还是开宗立派；打斗改成即时的斗法肉鸽；闭关、游历这些放置挂机玩法垫在底下。

本文是这次转向的方案：目标、原则、各系统怎么归位、斗法的技术做法和分阶段交付。现行规则仍以
[`pkg/wendao/world.md`](../pkg/wendao/world.md) 为准，每完成一个阶段同步改那份文档；
[长期方案](wendao-long-term-plan.md) 里与本文冲突的（卡牌构筑、三板块并列的入口）以本文为准，其余工作包照旧可做。

## 1. 目标

- **个人为主体**：主角就是玩家本人。开局是散修，没有宗门；之后三条路可以换着走：
  - **散修**：以洞府为家，接悬赏、去游历、闯秘境、在坊市买卖。自由，但没有宗门的俸禄与藏经阁。
  - **入宗门**：拜入正道诸宗之一（天剑宗、金刚寺、太虚观、万花谷），领俸禄、做宗门任务攒贡献，从外门弟子升到内门、
    真传、长老，用贡献在藏经阁换功法法宝。退出宗门要付代价（身份清零、一段时间不能再拜入）。
  - **开宗立派**：金丹以后凭师尊留下的宗主令重开问道宗山门（名号可以另起），现在的宗门经营（建筑、弟子、派遣、灵田、
    万宝阁、仙盟、大比、论剑）就是"自己的宗门"。之后开枝散叶：在别的地域开下院，弟子收徒，一脉传下去。
- **斗法即时肉鸽**：俯视角，移动走位，近战与远程法宝，流派法术，身法闪避；房间制，一间房分几波敌人，房间之间挑祝福和
  法宝，一层的尽头是首领。手机用虚拟摇杆，电脑用键盘鼠标。
- **放置挂机**：闭关修炼、游历（离线挂机历练）、灵脉打坐、宗门产出与派遣，离线最多补算 12 小时（`OfflineCap`）。

## 2. 原则

- **发游戏币的玩法必须公平、可核对**：斗法在浏览器里跑，服务端按同一个种子重放玩家的操作记录得出结果，不信浏览器报的
  胜负——和打砖块、飞扬小鸟、俄罗斯方块同一个做法。发币的模式（秘境无尽、宗门大比）照旧不带养成数值。
- **一份规则，两份实现**：斗法的规则 Go 写一份（服务端核对用，以它为准），浏览器 JS 逐行对照写一份。只用整数（定点）、
  固定 60 帧、同一个随机数发生器；数值与房间模板只有一份数据，从 Go 包复制给前端并由测试核对是否一致；黄金回放同时被
  `go test` 和 `bun test` 核对，任何一边改了规则另一边没跟上都会失败。
- **逐步替换，每一阶段都能玩、能发布**：卡牌战斗在斗法接手之前照常可用，接手之后整块删掉，不留两套战斗。
- **存档可以重整**：没有正式玩家，不为旧存档写迁移；但每次发版仍跑三库升级实测，保证旧库能起、旧存档读不了时明确提示
  而不是崩溃或写坏（`SaveSchema` 照旧递增）。
- **界面**延续水墨淡彩（`wendao.css` 的 `--wd-*` 变量，浅色深色都要好看），不用渐变光晕和发光；减少动态效果时去掉
  震屏与闪白；每段新文案七种语言都要有。

## 3. 现有系统怎么归位

| 现在 | 转向以后 |
|---|---|
| 主角（`Hero`） | 玩家本人。境界、功法、法宝、丹药都是个人的 |
| 宗门资源 `Sect.Res` 兼作主角的钱包 | 拆开：个人钱包（灵石、灵草、玄铁、声望）与宗门库房；开宗时从个人钱包拨一笔进库房 |
| 开局就是问道宗宗主 | 开局是散修；师尊坐化前把宗主令交给主角，金丹以后才能凭它开宗立派 |
| 洞府（静室、灵泉、丹室、器室、兽苑） | 散修的家，三条路都保留 |
| 宗门经营全套 | "自己的宗门"，开宗立派以后才出现 |
| 宗门大比的对手门派（天剑宗等） | 可以拜入的 NPC 宗门，各有俸禄、任务、藏经阁与流派倾向 |
| 卡牌战斗（`pkg/dungeon`） | 斗法（`pkg/doufa`）。功法从"卡牌"变成"法宝、法术与被动"；接手完成后删掉 `pkg/dungeon` 的战斗 |
| 九幽秘境（卡牌肉鸽，发币） | 斗法肉鸽，发币规则不变（只带流派与道韵天赋） |
| 历练五章、问心阶、周天试炼 | 剧情与节点保留，战斗换成斗法；地图并进世界地图的五个地域 |
| 闭关、派遣、灵田 | 放置挂机的底子，再加游历与灵脉 |

剧情衔接：主角原本是问道宗的末代弟子、开局就接任宗主。改成主角是落枫镇一带的散修，序章里云渺真人坐化前把宗主令交给
主角（"问道宗不能断"），主线照旧追查九幽封印。宗主令是开宗立派的凭证；拜入太虚观的玩家会在第四、五章亲眼看到观主
太虚真人的真面目，可以借此做专门的剧情分支。

## 4. 斗法（即时肉鸽）

### 4.1 手感

- 俯视角，房间由格子组成（墙、柱、石头挡人也挡弹）。镜头跟着主角，房间比屏幕大时平移。
- 主角：生命、灵力；**近战**法宝不耗灵力，挥砍扇形范围内的敌人，还能打掉扇形里的敌方飞弹；**远程**法宝每发耗灵力；
  每个流派一个**法术**（冷却 + 灵力）；**身法**是短距离冲刺，冲刺期间无敌，有冷却；挨打后短暂无敌。
- 流派法术：体修「震地」（身边一圈伤害并击退）、法修「焚天」（向四周放一圈火球）、剑修「剑阵」（几把飞剑绕身旋转）。
- 起手法宝：长剑（近战）、飞剑（远程、穿透一个）、符箓（远程、三发散射）；以后加入更多法宝与被动祝福。
- 敌人分几种行为：追身近战、保持距离放弹、蓄力冲撞（冲完会喘一下）、原地炮台放一圈弹、首领（几套弹幕轮换，半血加强、
  召小怪）。出怪前地面先有标记，敌方飞弹用朱砂色，与我方区分清楚。
- 电脑：WASD/方向键移动，鼠标瞄准、左键攻击（不动鼠标时自动瞄最近的敌人），右键或 K 放法术，空格或 Shift 身法，
  Q 换法宝，Esc 暂停。手机：左下摇杆，右下攻击（自动瞄准）、法术、身法、换法宝四个键；横屏竖屏都能打。
- 页面切到后台自动暂停；减少动态效果时不震屏不闪白。

### 4.2 规则与核对

- 规则包 `pkg/doufa`，浏览器对照 `web/classic/src/pages/Games/wendao/doufa/engine.js`。坐标单位是百分之一像素的整数，
  格子 32 像素；方向是 64 个角度，用一张整数正余弦表（两边同一份字面量）；求方向用点积选最近的角度，不用三角函数和浮点；
  随机数是 32 位异或移位。实体每帧按固定顺序更新：主角、敌人（按编号）、飞弹、掉落。
- 每帧的输入压成一个整数：移动方向（无或 64 个角度之一）、瞄准方向（自动或 64 个角度之一）、按住的键（攻击、法术、身法、
  换法宝）。上传时做游程压缩再 base64。
- 一间房一次核对：服务端发给浏览器房间种子和进房时的状态（生命、灵力、法宝、祝福），浏览器打完提交这间房的输入记录，
  服务端重放：打通了才记下新状态、发下一间房。每间房帧数有上限；提交时间不能早于"帧数 ÷ 60"秒的八成（防加速）。
- 数值与房间模板写在 `pkg/doufa/content.json`，Go 用 `go:embed` 读，前端读一份复制件，测试核对两份一字不差
  （`UPDATE_CONTENT=1` 重新复制）。
- 黄金回放：`pkg/doufa/testdata/generate_golden.mjs` 用前端规则跑几段脚本化的操作，记下最后的状态与逐帧校验和；
  Go 测试重放核对，前端测试再跑一遍核对，两边都要等于这份记录。

### 4.3 肉鸽一轮（第二阶段）

- 一层若干间房：战斗房（几波敌人）、精英房、祝福房（三选一）、宝库（法宝）、静修（回血）、首领房；房间之间在小地图上选路。
- 祝福是一轮里的被动（攻速、穿透、暴击、生命上限、法术冷却……），出了秘境就没有；道韵天赋在开局生效，流派由天赋解锁。
- 秘境无尽与试炼的领奖照旧按到达的重数，养成数值不进秘境。

## 5. 身份与世界（第三阶段）

- **世界地图**：五个地域（青岚山、赤霞原、北冥寒渊、万妖林、九幽）对应五章，每个地域有城镇（坊市、悬赏榜）、宗门山门、
  秘境入口、灵脉、险地。主线节点照旧按章节开放，放在对应地域里。
- **个人钱包**与宗门库房分开；功法参悟、洞府扩建、炼丹炼器花个人的；宗门建筑与弟子花库房的。
- **散修**：悬赏榜（每天几张，打斗法或送材料），坊市买卖。
- **入宗门**：四个 NPC 宗门各有倾向（天剑宗剑修、金刚寺体修、太虚观法修、万花谷丹道）；入门试炼一场斗法；俸禄按身份
  每天领；宗门任务给贡献；藏经阁用贡献换法宝、法术、丹方；身份按境界与贡献晋升；退出清零且七天内不能再拜入。
- **开宗立派**：金丹、有宗主令、不在任何 NPC 宗门里，拨一笔灵石开宗，解锁现有宗门经营。
- 存档：`Save` 加身份与钱包，`Sect` 只在开宗以后才有；`SaveSchema` 加一。

## 6. 放置与挂机（第五阶段）

- **游历**：选一个已经去过的地域挂机，按时长与主角强弱带回修为与材料，离线最多补算 12 小时；游历期间不能进斗法。
- **灵脉打坐**：在地域里的灵脉打坐，闭关修为加成；后期可做占灵脉的玩家互动。
- 回流说明（`Sect.Back`）扩到主角：离开很久回来时一并写明闭关、游历补算了多少。

## 7. 分阶段交付

| 阶段 | 内容 | 验收 |
|---|---|---|
| S1 斗法内核与试剑台 | `pkg/doufa` 与前端规则、黄金回放、内容复制件核对；画布水墨渲染、键鼠与触屏操作；历练页「试剑」页签：选流派与法宝，打一间分波刷怪的房间加首领，不发奖励、不调接口 | 两边黄金回放一致；电脑 60 帧流畅；手机 390 宽竖屏与横屏能打；浅色深色都看过 |
| S2 秘境斗法 | 一轮的会话与逐间核对、选路、祝福、法宝、首领；九幽秘境换成斗法，领奖规则不变 | 断网重发不重复结算；伪造输入或加速被拒；三库升级实测 |
| S3 身份与世界 | 个人钱包、散修开局、世界地图、四个 NPC 宗门、开宗立派 | 三条路都能走通并来回切换；旧存档明确提示 |
| S4 历练换斗法 | 章节节点、问心阶、周天试炼改用斗法；删除卡牌战斗 | 五章首领可通关；问心阶 50 级难度曲线重新模拟 |
| S5 放置挂机 | 游历、灵脉、回流说明扩展 | 离线补算上限正确；与斗法互斥 |
| S6 开枝散叶 | 下院、弟子收徒传承 | 下院产出与派遣正确 |

每完成一个阶段（或其中可用的一块）就快进合入 main 推送；打 tag 发版要另外说。
